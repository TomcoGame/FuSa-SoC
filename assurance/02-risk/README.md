# Risk analysis

Maintain hazards and cybersecurity threats separately but link threat-to-hazard effects where applicable.

- `hazards.csv`: preliminary hazard register; entries must not be mistaken for a completed HARA.
- Automotive HARA requires item context, operational situations, severity, exposure, controllability and ASIL derivation.
- IEC 61508 hazard/risk assessment requires defined safety functions and justified target integrity.
- TARA methodology, attack feasibility and cybersecurity goals belong in `../10-cybersecurity/`.

No ASIL or SIL target is assigned until a defensible assessment exists.
